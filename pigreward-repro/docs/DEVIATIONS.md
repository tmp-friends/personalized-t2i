# 公開PIGRewardとの相違

- 公式sourceの存在を仮定せず、checkpointだけを `artifacts/evaluator` に取得した独自adapter。
- 専用タスクtemplateの完全な公式実装は取得していない。`worker.py:TEMPLATE` はモデルカードの出力例を参考にした独自指示。
- 画像入力はRGB、縦横比を保った長辺448px。Qwen2-VL processor側のtoken上限も固定。
- parser `card-v1` はモデルカード例の軸別比較、合計、明示的winnerを扱う。合計と軸別点数の矛盾、欠損、同点、EOSなし、複数winnerを棄却。公開物が全比較共通の尺度を保証したとは扱わない。
- bootstrapは取得・使用していない。展示履歴の理由はQwen3.5-4Bの実画像解析を事前実行し、軸ごとに確認した節のみを利用 (`context_source=generic_vlm`)。
- 改変前のVLM出力は固定assetの監査用。来場者のOFF/訂正後には生成・推薦の別経路で渡さない。
- 4枚の完全順位は作らず、3比較による勝者だけを扱う。
- モデルのロード成功・少数比較の成功はライブ採用の条件を満たさない。設計書G0の20組・反転一致、時間、プロセス切替の結果を確認するまで推薦は無効。
- 原論文の精度や勝率を、この実装の性能として表示しない。
