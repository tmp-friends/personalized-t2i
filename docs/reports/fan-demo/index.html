G0 で確定した設定と根拠

  • skip_pa：skip_pa未指定（平均 laplacian_var 70.1 → 平均 saturation 32.3）から skip_pa=[0..7]（平均 laplacian_var 91.8 → 平均 saturation 40.8）で、ぼやけ（laplacian_var低下）と彩度低下が改善しました（2枚 vs 2枚の記録）。
  • use_attn_mask：use_attn_mask=True では alpha=0（参照ゼロ相当）でも hidden state の平均コサイン類似度が 0.59まで下がり、参照なしのFANエンコードと一致しません（use_attn_mask=False では1.0）。そのため use_attn_mask は無効のまま採用しています。
  • 参照の分け方：one-long-ref-per-card（結合文）とsplit（側面ごとの短い句）は同じ参照でも 画素MAEで12.581〜24.123の差が出ます（bundled_vs_split, 4条件）。 alpha=0.6でsplitとaspect-major（側面ごとにカードをまとめた1文）を比べると、laplacian_varはsplitが[81.0, 133.4]、aspect-majorが[75.1, 115.8]で、記録した2枚ともsplitが上回りました。 現在の実装（exhibit.domain.build_personalization）は側面ごとの短い句をカード横断でマージし、重みを合算する方式です。
  • alpha ladder：weak=0.35 / mid=0.5 / strong=0.6 を採用しています。目視の確認では、alpha=0.7でtokyoのお題の1boyという被写体の指定が崩れ始め、alpha=0.8では緑の瞳の指定が失われました。（傍証: tokyoのbaseline laplacian_varは約85.9に対し、alpha=0.7では[446.7, 276.9, 215.1, 104.5]まで跳ね上がる記録があり、崩れと符合します）そのため0.6を上限にしています。崩れの判定自体は目視によるもので、性能の定量主張ではありません。
  • warm_soft の lighting：既定の "soft lighting, gentle shadows" から "warm golden hour light, gentle shadows" に変更しました（ladder.json の reference_sets s1 → s1p）。 現在の configs/demo.json にもこの文言が入っています。
  • pooled：常に参照なし（plain）の pooled embedding を使います。個人化するのは hidden state だけです。

いずれも少数seed・少数条件の記録であり、性能を主張するものではありません（設計書 §9）。

説明で守っていること（設計書 §9）

  • 「来場者ごとの追加学習なし」と言います。「追加モデル・重みが一切ない」とは言いません — FAN公式実装の ClassTokenDecoder（weight/L.pth, weight/bigG.pth）を使っています。
  • 参照は「選んだ画像に付けた確認済みの説明文」です。画像そのものをエンコーダーへ入れているとは説明しません。
  • 反映を強くするほど良いとは言いません。targetとのバランスは来場者が判断します。
  • 論文の定量結果をこの展示の性能として使いません。ブラインド比較の集計は少人数の記録であり、性能主張にしません。
  • Attentionの値から「この画像がこの色を生んだ」といった因果説明はしません。参照に使った画像・説明文・強度だけを表示します。
  • 個人化時の pooled 埋め込みは、ClassTokenDecoder がpadding tokenを終端と誤検出するため使わず、同じ文の参照なし pooled を使います（意図した上流からの逸脱。詳細は exhibit/README.md）。
