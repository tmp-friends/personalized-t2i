# e10-mask 画素指標（metrics.md）

色の指標は 256x320 に縮小して測る。`darkline` だけ原寸で、自分自身の GaussianBlur(2.0) より 18 以上暗い画素の割合（%）。`target` は harness の CLIP target_score と、同じ topic × seed の plain との差。

基準はどの policy も実験自身の plain 列（`legacy_exhibit`）。`use_attn_mask` は参照の pad だけを key から外すので、参照なしの encode は素の pipeline と一致する。
