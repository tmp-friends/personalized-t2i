# e11-sampler · 生成設定でアーティファクトが消えるか（2026-09-23）

mask あり（`mask-skip1-alpha0.5` / `0.7`）の画像が原寸で「線が溶ける・髪が筋になる・白っぽい」
と見える件の、生成設定側の切り分け。policy は固定し、生成設定だけを 3 通り変えた。

- `e11a-guidance7` — guidance_scale 5.0 → 7.0
- `e11b-nonsde` — sampler を非 SDE の DPM++ 2M（Karras）に、steps 30 のまま
- `e11c-steps50` — 現行 sampler のまま steps 30 → 50
- 対照は `e10-mask`（現行設定）の同一セルを再利用

各 78 枚、新規 234 枚。history は warm / cool / t2-flat-graphic / warm-sun、
topic cat / forest / cafe、seed 2 本。**variant ごとに plain を焼き直している**ので、
Δ はすべて同じ設定内の比較。生成設定を上書きしているため rules は参考値。

結論を先に書く。

- **アーティファクトの正体は「高周波の増加」ではなく「細部の消失」。**
  ラプラシアン分散比は全 variant・全 alpha で 1 を下回る（0.28〜0.67）。
  二重輪郭が増えているのではなく、線と髪のディテールが落ちている。
  白飛びも増えていない（Δblown はすべて負）。
- **非 SDE sampler が明確に効く。** alpha 0.5 で彩度の落ち込みが 1/3 に、
  ラプラシアン比が 0.39 → 0.67 に、線（darkline）の消失が 1/3 になる。**時間コストはゼロ。**
- **guidance 7.0 は悪化。** 彩度もラプラシアンも白飛びも対照より悪い。
- **steps 50 はわずかな改善だが 1.6 倍の時間。** 割に合わない。

## 目視

`crop-<variant>.jpg` が原寸の顔切り出し（624 px）、列は plain / α0.5 / α0.7。

- **control** — plain は髪と目に黒い線がはっきり残る。α0.5・0.7 では線が溶け、
  髪が筋状の淡い塊になり、全体が白茶けて見える。報告どおりの症状。
- **nonsde** — plain 自体がやや軟らかい描画になるが、α0.5・0.7 が plain に近い。
  髪の束がまとまりを保ち、目の輪郭も残る。白茶けが消える。
  **plain と個人化の差が対照よりはっきり小さい。**
- **guidance7** — コントラストは上がるが白飛びが増え、個人化側の色抜けが目立つ。
- **steps50** — 対照とほぼ同じ見え方。

## 推奨

**`e11b-nonsde` の設定（非 SDE の DPM++ 2M・Karras・steps 30）を採る。**

- 彩度の落ち込みが α0.5 で −18.65 → −6.55、α0.7 で −24.26 → −13.01。
- 細部の消失が α0.5 で 0.391 → 0.674、線の消失が −2.90 → −0.92。
- 1 枚 5.04 秒で現行（5.02 秒）と同じ。**追加コストなしで最大の改善。**

ただし 2 点の注意。

1. **sampler を変えると plain も変わる。** 非 SDE の plain は現行より軟らかい描画になる。
   展示のカード・サンプルを作り直す判断とセットになる。
2. **Δtarget はわずかに悪化する**（α0.5 で +0.004 → −0.007）。
   被写体保持の観点では現行 sampler の方が僅かに良い。実用上は小さい差。

`e11c-steps50` は改善幅が小さく時間が 1.6 倍なので採らない。
`e11a-guidance7` は悪化するので採らない。
